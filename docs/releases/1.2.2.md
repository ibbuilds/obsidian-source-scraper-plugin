# Source Scraper 1.2.2 — visible processing and independent collection

Public enrichment progresses while Obsidian is open without a chat, model or
another source read. Native controls and MCP expose bounded continuation and
explicit retry of exhausted pages. Progress distinguishes real fetches and
completions from queued, unavailable and blocked evidence.

Automatic resource assessments now require the inspected profile hash and are
isolated by project and criteria. Legacy unscoped assessments remain in history;
they are not silently assigned to a new profile. Human Keep/Hide remains durable. The optional Require topic review setting
keeps uncertain evidence out of the default catalogue while retaining review routes.
Passing structural resource checks never queues a like. Resource-origin like
requests additionally require an independent current full-post topic decision;
all new actions dispatch through the reviewed-post snapshot contract.

Continuous collection has its own native toggle and MCP argument, independent of
automatic resource checks. X reads are paced at one page per two minutes between
work-limit batches. Read 429 responses schedule persisted 15/30/60 minute cooldowns
or longer safe server deadlines; repeated failures block. Pause/Stop and restart
cannot bypass a saved cooldown. Like dispatch never uses this retry policy.

The tested integration pins engine 0.16.1 and the existing reviewed 64-tool host
extension. There are still 33 provider tools. Installation preserves projects,
encrypted sessions, user choices and existing read/like grants. Feedback stays off
unless the user explicitly enables it. No notes are written by this plugin.
