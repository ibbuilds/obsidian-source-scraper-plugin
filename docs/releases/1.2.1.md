# Source Scraper for Obsidian 1.2.1 — complete MCP registration

The 1.2.0 provider defines 33 tools. The previous provider-API host build allowed
at most 32, so it rejected the entire provider even though local collection and
review still worked. Upgrade with this integration bundle to update the host.

- The existing host's reviewed patch now accepts up to 64 namespaced tools from
  an already locally enabled trusted provider. Duplicate names/IDs, foreign
  prefixes, argument checks, revocation, authentication and note ACLs are unchanged.
- Both host CI and integration-bundle CI register the complete actual Source
  Scraper provider with the actual patched host registry and dispatch its
  capabilities operation. This regression fails against the previous host.
- Host tests cover 33 tools, the allowed 64-tool boundary and rejection at 65.
- The patch digest is updated in the compatible-set metadata; old release bytes
  remain immutable. Engine 0.16.0 and all 33 source tools remain unchanged.

Installation preserves projects, private decisions, session storage, notes and
the separate read/like grants. This patch does not enable feedback.
