# Source Scraper for Obsidian 1.2.0

Resources now opens matching candidates by default, including resources awaiting
quality review. Enable **Require quality qualification** explicitly to start with
Qualified. Status counts use the same authoritative query as the working inbox.

- Native topic review works without AI for retained posts or selected resources.
  Posts without links can be relevant for feed feedback without inventing sources.
  Topic review pending and Outside topic views preserve uncertain/negative cases.
- Five additive MCP tools expose the same evidence and decisions: `get_posts`,
  `review_posts`, `get_relevance`, `review_relevance`, `process_pending`.
  A post review defaults to a dry run. `queueLike: true` also requires enabled
  feedback and the separate existing local grant; it does not turn either on.
- Decisions bind to the current evidence and profile. Every supplied visual must
  be reviewed. Explicit human choices prevail and obsolete replay receipts cannot
  authorize new feedback. Existing rate limits and uncertain-send reconciliation
  are shared by old and new queues.
- Resuming a cycle reconciles committed progress before assigning the new page
  budget. Bounded partial jobs finish as partial instead of false source failures.
  Temporary read/transport timeouts use the bounded persisted retry policy.
- Public enrichment continues in bounded background batches. Private audit history
  moves to immutable content-addressed archives; explicit reviews and confirmed
  feedback deduplication remain in the active ledger.

Use the compatible engine 0.16.0 and existing provider-API host. Existing profiles,
notes, sessions, permissions and human decisions are preserved. No source-owned
note writer, new model provider or paid fallback is introduced. An AI client must
actually inspect evidence; there is no hidden background model when chat closes.
Representative held-out human labels are still required to claim semantic accuracy.
