# Source Scraper for Obsidian 1.1.0

This release packages the current 28-tool review-only MCP integration with engine 0.15.0 and the reviewed provider-API build of the existing Vault as MCP host. It does not add a second server or any source-owned note writer.

- Explicit integration diagnostics distinguish local registration, trusted executable compatibility, project manifests and cloud-tool discovery. The diagnostic runs only the trusted CLI version command; no X probe or collection.
- A default-dry-run installer validates bundle digests, changes only fixed plugin assets/configuration and an external runtime, preserves private host settings and existing projects, creates backups and rolls back owned writes after failure.
- Reproducible integration bundles include exact commit and artifact fingerprints, the reviewed host patch provenance, licenses and installation instructions.
- MCP tool definitions are isolated per consumer and report external-action annotations for X-capable operations accurately.
- Existing note ACLs, legacy plugin data, human reviews and sessions are not migrated or deleted. X read/like grants are never enabled by the installer.

The suite exercises synthetic installation, tampering, symlinks, failure recovery, actual CLI/provider contracts and real Obsidian Desktop in an isolated vault. None of those tests prove installation on the user's device, a refreshed ChatGPT tool inventory, or current X-session access. Those checks remain explicit final acceptance steps.
