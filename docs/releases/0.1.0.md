# Source Scraper for Obsidian 0.1.0 — independent preview

First independent **general-purpose** Obsidian client for Source Scraper JSON.

## What works

- Native sidebar with project entities, source evidence, scores and human-review status.
- Import Source Scraper versioned entity JSON/NDJSON from a vault file or pasted data.
- Search, inspect and select entities (including records with no URL).
- Preview generic Markdown and deterministic destination paths.
- **Create new files only**, explicit folder/record confirmation and conflict reports. Does not modify, rename, delete, trash or overwrite existing notes, including existing `References.md`.
- Optional, manually triggered local standalone Source Scraper CLI connection. JSON import works without a separate Node CLI. With a matching configured engine project, human reviews can be explicitly saved with a required reason; there is no direct SQLite editing.
- Cross-platform Node unit/security tests, genuine JSON v1 from the independently built engine, and six real Obsidian Desktop E2E scenarios in an isolated disposable vault.

## How to install manually

Download `main.js`, `manifest.json` and `styles.css` from **this release**, place in `<vault>/.obsidian/plugins/source-scraper/`, reload Obsidian Desktop (1.9.2+) and enable Source Scraper under Community plugins.

**Not yet listed in Obsidian's Community plugin directory.** This is a manual preview build, not confirmation of directory approval.

## Safety and limitations

Only JSON `schemaVersion:1` entity exports are accepted; `observations/alerts/changes` cannot be imported as entity notes. No automatic sync, GUI rule-building, cloud service, personalized X For You feed, auto-approval or edits of existing notes. Pending, rejected and approved statuses are displayed from original data; users explicitly choose which to create as notes.

Old `Discovery Engine` plugin with ID `x-feed-scraper` is untouched. No vault migration or deletion. See [user guide](https://github.com/ibbuilds/obsidian-source-scraper-plugin/blob/0.1.0/docs/USER-GUIDE.md) and [safety policy](https://github.com/ibbuilds/obsidian-source-scraper-plugin/blob/0.1.0/docs/SAFETY.md).
